How we work

We build AI that runs at the edge, on hardware sized for the site, connected to the sensors and machines already there, and watched remotely. Here is how a deployment comes together.

  • Building the model
  • Sizing the edge server
  • Industrial IoT
  • Remote operation

1. Building the model

Every model starts from one operational problem, not from a technique. We work through it in the same order each time, so you can see where a project stands.

  1. Define the problem. Agree what the model must detect, measure or decide, and what counts as good enough on site.
  2. Prepare the data. Collect and clean images or sensor readings from the real environment.
  3. Choose the model. Pick an approach that fits the job and the hardware it will run on.
  4. Train it on the prepared data.
  5. Evaluate it against the targets agreed in step one.
  6. Tune it until it meets those targets on site conditions.
  7. Deploy it to the edge device on site.

2. Sizing the edge server

Running models on site means results do not wait on a link to the cloud. That only works if the hardware is sized for the real load and the real environment. We size each industrial edge server in five checks.

  1. Workload. How many models, cameras and sensors, and how often each must run.
  2. Compute and storage. The processors, accelerators and storage that workload needs.
  3. Network and latency. How fast results must arrive, and what links the site has.
  4. Power and thermal. What the site can supply and how hot or exposed the device will be.
  5. Test. Run the full workload on the chosen hardware before it goes live.

3. Industrial IoT

Sensors give the models something to work with and show where assets are. We use outdoor-rated hardware and keep the network secure from sensor to dashboard.

  • IP67 outdoor-rated sensors
  • UWB, BLE and active tags for location and occupancy
  • Asset and location tracking
  • Predictive maintenance and real-time monitoring
  • Secure industrial IoT architecture

4. Remote operation and digital twins

Robots and sensors are linked to a 3D digital twin of the site, so your team can see what is happening and take control remotely.

  • 3D digital twin for remote control and monitoring
  • Digital twins and augmented reality for manufacturing
  • Cloud design, implementation and management
