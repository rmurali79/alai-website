SensZ.AI

An edge AI module with an IP67 outdoor sensor, for object detection and live volume and weight measurement.

Request a demo

What it does

SensZ.AI puts a trained model next to the sensor, so detection happens on site rather than in the cloud. The sensor is rated IP67 for outdoor use, and the module supports custom models for object detection and real-time measurement of volume and weight.
